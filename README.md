# Tiny Wonder World

Interactive bilingual (**English & Tamil**) learning app designed for toddlers and kids (ages 1–5) with slow-motion voice guidance and playful picture boards.

## Features
- **Bilingual Voice Support**: Learn in both **English** and **Tamil (தமிழ்)** with clear, slow-paced speech (`expo-speech`).
- **Interactive Picture Boards**: Touch-to-listen boards for:
  - **Alphabets (A to Z)**
  - **Counting (1 to 20)**
  - **Animals**
  - **Fruits**
  - **Shapes**
  - **Colors**
- **Responsive Design**: Works smoothly on mobile phones, tablets, and web browsers.

## How to Run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the app:
   ```bash
   npx expo start -c
   ```
